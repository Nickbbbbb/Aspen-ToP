# AspenToTop.exe 使用说明

本工具只提供四个用户功能：

1. 单个 `.bkp` 文件转 `.hss`
2. 批量 `.bkp` 文件转 `.hss`
3. 单个 `.hss` 文件转 `.bkp`
4. 批量 `.hss` 文件转 `.bkp`

## 环境要求

- Windows
- 已安装 Aspen Plus，并且 Aspen COM 接口可用
- 转 `.bkp` 时不要同时手动打开同名 Aspen 文件

## 1. 单个 BKP 转 HSS

```bat
AspenToTop.exe bkp-to-hss "test_files\column\乙烯塔.bkp" -o "output\乙烯塔.hss"
```

如果不写 `-o`，默认输出到 `output\<同名>.hss`。

## 2. 批量 BKP 转 HSS

```bat
AspenToTop.exe batch-bkp-to-hss "test_files\flash" -d "output_hss"
```

批量模式只扫描输入文件夹第一层的 `.bkp` 文件。

## 3. 单个 HSS 转 BKP

```bat
AspenToTop.exe hss-to-bkp "test_files\column\乙烯塔.hss" -o "output\乙烯塔.bkp"
```

如果不写 `-o`，默认输出到 `output\<同名>.bkp`。

## 4. 批量 HSS 转 BKP

```bat
AspenToTop.exe batch-hss-to-bkp "test_files\column" -d "output_bkp"
```

批量模式只扫描输入文件夹第一层的 `.hss` 文件。

## Column 核心测试

交付测试包中 `test_files\column` 放了两个核心精馏塔样例：

- `乙烯塔.bkp` / `乙烯塔.hss`
- `脱丁烷塔.bkp` / `脱丁烷塔.hss`

建议优先验证：

```bat
AspenToTop.exe hss-to-bkp "test_files\column\乙烯塔.hss" -o "output_bkp\乙烯塔.bkp"
AspenToTop.exe hss-to-bkp "test_files\column\脱丁烷塔.hss" -o "output_bkp\脱丁烷塔.bkp"
```

## 测试文件说明

`test_files` 按模块分文件夹，每个普通模块提供两个测试 case；每个 case 同时提供 `.bkp` 和 `.hss`，方便分别验证正向和反向转换。

当前包含：

- `column`: 乙烯塔、脱丁烷塔
- `flash`
- `heater`
- `valve`
- `pump`
- `mixer`
- `compressor`
- `heatx`
- `splitter_fsplit`

## 常见问题

- 如果提示 Aspen 打不开文件，先确认该 `.bkp` 能否在 Aspen Plus 中手动打开。
- 如果 HSS 转 BKP 失败，确认 Aspen Plus COM 可用，并关闭正在占用同名文件的 Aspen 窗口。
- 路径中包含中文或空格时，请给路径加英文双引号。
