# Aspen-ToP 使用说明

## 环境要求

- Windows
- 已安装 Aspen Plus，并且 COM 接口可用
- Python 环境可导入：
  - `pythoncom`
  - `win32com.client`
  - `Crypto`

HSS 加密依赖外部工具 `export-test/hss_file_tool.py`。如果加密时报缺少 `pycryptodome`，执行：

```bash
python -m pip install pycryptodome
```

如果机器上有多个 Python，请确认依赖安装到执行 `python main.py` 的 Python 环境。

## 推荐用法

把 BKP 转为 HSS，并保留可检查 JSON：

```bash
python main.py "C:\path\to\case.bkp" -i
```

输出：

```text
output\case.hss
output\case.json
output\case.extracted.json
```

说明：

- `case.hss`: ToP 导入文件。
- `case.json`: 最终 ToP JSON，也就是被加密进 HSS 的内容。
- `case.extracted.json`: Aspen COM 提取后的标准化中间数据。

## 单文件转换

```bash
python main.py examples\single_bkp\alkane.bkp
```

默认输出到：

```text
output\alkane.hss
output\alkane.json
```

指定输出路径：

```bash
python main.py examples\single_bkp\alkane.bkp -o output\alkane.hss
```

## 批量转换

传入一个文件夹：

```bash
python main.py examples\batch_bkp -i
```

也可以直接传入多个 BKP：

```bash
python main.py a.bkp b.bkp -i
```

批量转换时使用默认输出目录或 `--output-dir`，不要使用 `-o`，因为 `-o` 表示单个 HSS 文件路径。

## 分步调试

分步调试用于定位问题发生在 Aspen 读取、ToP JSON 构建还是 HSS 加密阶段。

### 只提取 Aspen 数据

```bash
python main.py case.bkp --extract-only output\case.extracted.json
```

重点检查：

- `components`
- `blocks`
- `streams`
- `methad`
- `processGraph`

### 只构建 ToP JSON

```bash
python main.py --build-only output\case.extracted.json --top-json output\case.json
```

### 只加密 HSS

```bash
python main.py --encrypt-only output\case.json -o output\case.hss
```

### 解密 HSS

```bash
python main.py --decrypt output\case.hss output\case.decrypted.json
```

## Python API

推荐使用两个统一接口：

```python
from aspen_to_top import convert_single_bkp, convert_bkp_folder

convert_single_bkp("examples/single_bkp/alkane.bkp")
convert_bkp_folder("examples/batch_bkp")
```

分步 API：

```python
from aspen_to_top import extract_bkp_data, build_top_json, encrypt_to_hss

extract_bkp_data("case.bkp", "output/case.extracted.json")
build_top_json("output/case.extracted.json", "output/case.json")
encrypt_to_hss("output/case.json", "output/case.hss")
```

## ToP 导入失败排查

1. 检查 `output\case.json` 是否为合法 JSON。
2. 检查 `omProcessGraph.processNodes` 中节点 ID 是否重复。
3. 检查每条 `processEdges.source.cell` 和 `processEdges.target.cell` 是否能在节点 ID 中找到。
4. 检查每条 `processEdges.source.port` 和 `processEdges.target.port` 是否存在于对应节点的 `ports` 中。
5. 检查 Source/Sink 坐标是否从 BKP 读取。
6. 检查设备 `nodeProperties` 是否缺少关键字段。
7. 使用 `--decrypt` 解密 HSS，确认 HSS 中内容与 `case.json` 一致。

## 常见问题

### 运行时找不到 BKP

确认路径存在，路径中有中文或空格时加引号：

```bash
python main.py "C:\Users\Administrator\Downloads\Aspen-ToP\examples\single_bkp\alkane.bkp" -i
```

### 加密时报 Crypto 相关错误

先确认 Python 路径：

```bash
python -c "import sys; print(sys.executable)"
```

然后安装依赖：

```bash
python -m pip install pycryptodome
```

### Aspen 打开失败

检查：

- Aspen Plus 是否安装。
- BKP 文件是否能手动打开。
- 运行用户是否有 COM 权限。
- 是否存在占用 BKP 文件的 Aspen 进程。
