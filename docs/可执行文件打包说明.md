# 可执行文件打包说明

## 目标

将项目打包为 Windows 下可直接执行的 `AspenToTop.exe`，并继续支持命令行完成：

- 单个 `.bkp` 文件转换
- 文件夹内多个 `.bkp` 文件批量转换

## 打包方式

项目使用 `PyInstaller` 打包。

打包时会一并带上以下运行时资源：

- `Template/`
- `export-test/`

这两个目录中的内容仍然保留原有功能，不修改外部加密工具逻辑。

## 一键打包

在项目根目录执行：

```bat
build_exe.bat
```

打包完成后，生成文件位于：

```text
dist\AspenToTop.exe
```

## 手动打包

```bat
python -m pip install --upgrade setuptools pyinstaller
pyinstaller --clean AspenToTop.spec
```

## 运行说明

### 1. 单文件转换

```bat
AspenToTop.exe "C:\path\demo.bkp" -i
```

输出文件默认生成到：

```text
AspenToTop.exe 所在目录\output\
```

生成内容包括：

- `demo.hss`
- `demo.json`
- `demo.extracted.json`

### 2. 指定 HSS 输出路径

```bat
AspenToTop.exe "C:\path\demo.bkp" -o "C:\path\case.hss" -i
```

### 3. 批量转换文件夹

```bat
AspenToTop.exe "C:\path\bkp_folder"
```

程序会扫描该文件夹第一层中的所有 `.bkp` 文件，并逐个转换。

### 4. 批量转换并指定输出目录

```bat
AspenToTop.exe "C:\path\bkp_folder" -d "C:\path\output"
```

### 5. 只生成 ToP JSON

```bat
AspenToTop.exe "C:\path\demo.bkp" --json-only -i
```

### 6. 查看帮助

```bat
AspenToTop.exe --help
```

## 运行时路径约定

为兼容源码运行和 exe 运行，项目将路径分为两类：

### 1. 资源路径

用于读取：

- `Template`
- `export-test/hss_file_tool.py`

源码运行时从项目根目录读取；exe 运行时从 PyInstaller 解包目录读取。

### 2. 输出路径

用于生成：

- `.hss`
- `.json`
- `.extracted.json`

源码运行时默认输出到项目根目录下的 `output/`；
exe 运行时默认输出到 `AspenToTop.exe` 所在目录下的 `output/`。

## 注意事项

### 1. Aspen COM 运行环境

程序依赖本机已安装 Aspen Plus，并可通过 COM 接口打开 `.bkp` 文件。

### 2. 加密依赖

`HSS` 加密仍通过 `export-test/hss_file_tool.py` 调用。
打包只做路径适配，不修改原有加密实现。

### 3. 常见失败原因

- 机器上未安装 Aspen Plus
- Python 打包环境缺少 `setuptools`
- `.bkp` 文件路径不存在
- `Template` 或 `export-test` 未正确打包
