# 可执行文件打包说明

## 目标

将项目打包为 Windows 下可直接执行的 `AspenToTop.exe`，并继续支持命令行完成：

- 单个 `.bkp` 文件转换
- 文件夹内多个 `.bkp` 文件批量转换

## 打包方式

项目使用 `PyInstaller` 打包。

打包时会一并带上以下运行时资源：

- `Template/`
- `export-test/`

这两个目录中的内容仍然保留原有功能，不修改外部加密工具逻辑。

## 一键打包

在项目根目录执行：

```bat
build_exe.bat
```

打包完成后，生成文件位于：

```text
dist\AspenToTop.exe
```

## 手动打包

```bat
python -m pip install --upgrade setuptools pyinstaller
pyinstaller --clean AspenToTop.spec
```

## 运行说明

建议先把命令行切换到 `AspenToTop.exe` 所在目录，再执行下面的命令。

例如：这里选择直接的.exe文件的路径

```bat
cd /d C:\Users\Administrator\Downloads\Aspen-ToP\dist
```

### 1. 单文件转换

```bat
AspenToTop.exe "C:\path\demo.bkp" -i
```

输出文件默认生成到：

```text
AspenToTop.exe 所在目录\output\
```

生成内容包括：

- `demo.hss`
- `demo.json`
- `demo.extracted.json`

如果使用当前项目自带示例，可以直接运行：

```bat
AspenToTop.exe "..\examples\single_bkp\alkane.bkp" -i
```

对应输出通常在：

```text
dist\output\alkane.hss
dist\output\alkane.json
dist\output\alkane.extracted.json
```

### 2. 指定 HSS 输出路径

```bat
AspenToTop.exe "C:\path\demo.bkp" -o "C:\path\case.hss" -i
```

使用项目示例的真实命令：

```bat
AspenToTop.exe "..\examples\single_bkp\alkane.bkp" -o ".\case\alkane_case.hss" -i
```

### 3. 批量转换文件夹

```bat
AspenToTop.exe "C:\path\bkp_folder"
```

程序会扫描该文件夹第一层中的所有 `.bkp` 文件，并逐个转换。

使用项目示例的真实命令：

```bat
AspenToTop.exe "..\examples\batch_bkp" -i
```

### 4. 批量转换并指定输出目录

```bat
AspenToTop.exe "C:\path\bkp_folder" -d "C:\path\output"
```

使用项目示例的真实命令：

```bat
AspenToTop.exe "..\examples\batch_bkp" -d ".\batch_output" -i
```

### 5. 只生成 ToP JSON

```bat
AspenToTop.exe "C:\path\demo.bkp" --json-only -i
```

使用项目示例的真实命令：

```bat
AspenToTop.exe "..\examples\single_bkp\alkane.bkp" --json-only -i
```

该命令会生成：

- `alkane.json`
- `alkane.extracted.json`

不会生成 `.hss` 文件。

### 6. 仅提取 Aspen 数据到 JSON

```bat
AspenToTop.exe "C:\path\demo.bkp" --extract-only "data.json"
```

使用项目示例的真实命令：

```bat
AspenToTop.exe "..\examples\single_bkp\alkane.bkp" --extract-only ".\debug\alkane.extracted.json"
```

### 7. 仅将提取 JSON 构建为 ToP JSON

```bat
AspenToTop.exe --build-only "data.json" --top-json "top.json"
```

例如：

```bat
AspenToTop.exe --build-only ".\debug\alkane.extracted.json" --top-json ".\debug\alkane.top.json"
```

### 8. 仅将 ToP JSON 加密为 HSS

```bat
AspenToTop.exe --encrypt-only "top.json" -o "case.hss"
```

例如：

```bat
AspenToTop.exe --encrypt-only ".\debug\alkane.top.json" -o ".\debug\alkane.top.hss"
```

### 9. 解密 HSS 为 JSON

```bat
AspenToTop.exe --decrypt "case.hss" "case.json"
```

例如：

```bat
AspenToTop.exe --decrypt ".\output\alkane.hss" ".\output\alkane.decrypted.json"
```

### 10. 查看帮助

```bat
AspenToTop.exe --help
```

### 11. 查看版本

```bat
AspenToTop.exe --version
```

## 输出文件说明

### 1. `.hss`

ToP 软件导入文件。

### 2. `.json`

最终加密前的 ToP JSON。
如果 ToP 导入失败，应优先检查这个文件中的：

- `omProcessGraph`
- `processNodes`
- `processEdges`
- 各模块 `nodeProperties`

### 3. `.extracted.json`

Aspen COM 提取后的标准化中间 JSON。
如果发现模块参数不对、端口不对、侧线不对、组分不对，应优先检查这个文件。

## 运行时路径约定

为兼容源码运行和 exe 运行，项目将路径分为两类：

### 1. 资源路径

用于读取：

- `Template`
- `export-test/hss_file_tool.py`

源码运行时从项目根目录读取；exe 运行时从 PyInstaller 解包目录读取。

### 2. 输出路径

用于生成：

- `.hss`
- `.json`
- `.extracted.json`

源码运行时默认输出到项目根目录下的 `output/`；
exe 运行时默认输出到 `AspenToTop.exe` 所在目录下的 `output/`。

## 注意事项

### 1. Aspen COM 运行环境

程序依赖本机已安装 Aspen Plus，并可通过 COM 接口打开 `.bkp` 文件。

### 2. 加密依赖

`HSS` 加密仍通过 `export-test/hss_file_tool.py` 调用。
打包只做路径适配，不修改原有加密实现。

### 3. 常见失败原因

- 机器上未安装 Aspen Plus
- Python 打包环境缺少 `setuptools`
- `.bkp` 文件路径不存在
- `Template` 或 `export-test` 未正确打包
- 目标机器无法正常调用 Aspen COM

### 4. 排错建议

如果执行后 `.hss` 不能导入 ToP，建议按下面顺序排查：

1. 先使用 `--json-only -i` 保留中间文件
2. 检查 `.extracted.json` 是否已经把 Aspen 中的模块、流股和参数读取正确
3. 检查最终 `.json` 中的 `processNodes`、`processEdges` 和模块属性是否正确
4. 再确认是不是 ToP 对 JSON/HSS 内容本身不接受
