# 文件清理说明

本文档说明项目中各类文件的保留和清理规则。

## 运行必需文件

```text
main.py
run.bat
README.md
aspen_to_top/
Template/
export-test/hss_file_tool.py
docs/
examples/
```

说明：

- `main.py`: 根目录 CLI 入口。
- `run.bat`: Windows 便捷入口。
- `aspen_to_top/`: 主代码包。
- `Template/`: ToP JSON 模板，运行必需。
- `export-test/hss_file_tool.py`: 外部 HSS 加密工具，运行必需。
- `docs/`: 项目文档。
- `examples/`: 单文件/批量 BKP 转换演示。

## 示例文件保留策略

示例目录用于演示单个 BKP 和多个 BKP 的转换方式：

```text
examples/
  示例说明.md
  demo_convert.py
  single_bkp/
  batch_bkp/
```

建议只保留少量可运行的 `.bkp` 示例，避免把大量 Aspen 工程运行文件放入仓库。

## 缓存和系统文件

以下文件由 Python、IDE、macOS 或测试工具生成，可以清理并加入 `.gitignore`：

```text
__pycache__/
aspen_to_top/**/__pycache__/
export-test/__pycache__/
.pytest_cache/
__MACOSX/
```

## IDE 本地配置

```text
.idea/
```

建议：

- 团队共享的 PyCharm 项目配置可以保留。
- `workspace.xml` 属于个人本地状态，不建议提交。

## 可归档脚本

以下脚本属于辅助脚本或临时调试脚本，主流程不依赖：

```text
aspen_run.py
json_create.py
get_x_y.py
layout_fixed.py
hss_file_tool.py
test.py
test_aspen_result.py
```

建议：

- 需要保留参考价值时放入 `legacy/`。
- 不需要保留时删除。
- 根目录 `hss_file_tool.py` 与 `export-test/hss_file_tool.py` 功能重复时，只保留 `export-test/hss_file_tool.py`。

## 运行输出

以下文件属于运行输出或调试产物，不建议提交：

```text
aspen_fixed_data.json
final_result.json
process_edges.json
process_nodes.json
output/
test_output/
export-test/*.json
export-test/*.hss
```

注意：

- `export-test/hss_file_tool.py` 必须保留。
- `output/` 和 `test_output/` 建议加入 `.gitignore`。

## 源码包内文件规则

`aspen_to_top/` 只放 Python 源码和包内运行依赖，不放：

- `.bkp` 示例文件
- `.hss` 输出文件
- `.json` 调试输出
- `output/` 运行目录

示例文件统一放入 `examples/`。

## constants 目录

如果代码已经使用 `aspen_to_top/utils/chemical_mapper.py`，并且没有外部脚本引用 `constants`，可以清理 `constants/`。

删除前检查：

```bash
python -m compileall aspen_to_top main.py
```

## 推荐 `.gitignore`

```gitignore
__pycache__/

.pytest_cache/
.idea/workspace.xml
__MACOSX/

output/
test_output/

aspen_result/**/*.dmp
```

是否忽略 `.bkp` 取决于团队是否需要把示例流程文件纳入仓库。

## 清理流程

1. 确认 `examples/` 中保留了可运行的 BKP 示例。
2. 运行完整转换：

```bash
python main.py "examples\single_bkp\alkane.bkp" -o output\alkane.hss -i
```

3. 确认 ToP 可以导入生成的 `.hss`。
4. 删除缓存、运行输出和 IDE 本地状态文件。
5. 对可归档脚本按团队需要保留到 `legacy/` 或删除。
