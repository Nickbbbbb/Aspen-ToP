# Aspen-ToP 示例说明

这个目录演示两种常见场景：

- 单个 `.bkp` 转 `.hss`
- 多个 `.bkp` 批量转 `.hss`

## 目录结构

```text
examples/
  示例说明.md
  demo_convert.py
  single_bkp/
    alkane.bkp
  batch_bkp/
    mixer_test.bkp
    乙烯塔.bkp
    脱丁烷塔.bkp
    镇海三联塔（430-431-440）.bkp
```

## 单个 BKP 转换

在项目根目录运行：

```bash
python main.py examples\single_bkp\alkane.bkp -i
```

输出：

```text
output\alkane.hss
output\alkane.json
output\alkane.extracted.json
```

## 多个 BKP 批量转换

在项目根目录运行：

```bash
python main.py examples\batch_bkp -i
```

输出目录：

```text
output\
```

每个 `.bkp` 会生成同名：

- `.hss`
- `.json`
- `.extracted.json`

## 使用演示脚本

运行单文件演示：

```bash
python examples\demo_convert.py single
```

运行批量演示：

```bash
python examples\demo_convert.py batch
```

运行全部演示：

```bash
python examples\demo_convert.py all
```

演示脚本调用对外暴露的两个统一接口：

```python
from aspen_to_top import convert_single_bkp, convert_bkp_folder

convert_single_bkp("examples/single_bkp/alkane.bkp")
convert_bkp_folder("examples/batch_bkp")
```

## 运行要求

- 机器已安装 Aspen Plus。
- Aspen COM 接口可用。
- `.hss` 由 `export-test/hss_file_tool.py` 加密生成。
- ToP 导入失败时，优先检查同名 `.json`。
